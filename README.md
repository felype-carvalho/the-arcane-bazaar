# The Arcane Bazaar

A responsive D&D 5.5e magic item market and pricing guide built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

Node.js 20.19+ is required.

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run build
```

The catalog currently comes from typed mock data behind an asynchronous service boundary. It can later be replaced by a local JSON source without changing the UI.
